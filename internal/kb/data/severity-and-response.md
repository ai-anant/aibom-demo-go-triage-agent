# Severity and Response Policy

A suspected data breach, leaked credential or unauthorised access is a Sev-1
security incident. It must be escalated to the security on-call engineer within
15 minutes, in the security queue.

A full outage, data loss or payment processing failure is Sev-1 and belongs to
incident-response. Partial degradation or a single-tenant failure is Sev-2 and
belongs to incident-response as well, with a two-hour response target.

Refund requests above USD 500, duplicate charges and contract billing disputes
are high priority and belong to the billing queue. Finance must approve any
refund above USD 500.

Password resets, SSO misconfiguration and seat provisioning are normal priority
and belong to the account queue.

Feature requests, documentation questions and general how-to questions are low
priority and belong to the general queue.
